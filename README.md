# Sistema de Cadastro de Clientes
Projeto Full Stack de cadastro de clientes utilizando:

- ASP.NET Core Web API
- JavaScript
- jQuery
- Bootstrap
- Persistência em arquivo JSON/TXT
  
A API segue padrão REST utilizando os métodos:
GET, POST, PUT e DELETE.

## Funcionalidades

- Cadastro de clientes
- Listagem de clientes
- Atualização de clientes
- Remoção de clientes
- Integração Frontend + API
- Persistência de dados em arquivo local
- Documentação Swagger

## Tecnologias utilizadas

### Backend
- C#
- ASP.NET Core
- Swagger

### Frontend
- HTML
- CSS
- JavaScript
- jQuery
- Bootstrap

## Arquitetura

O projeto foi dividido em:

- Frontend responsável pela interface do usuário
- Backend responsável pela API REST
- Persistência local utilizando serialização JSON

## Executando

### Backend
1. Abra o projeto no Visual Studio
2. Execute a API ASP.NET Core
3. O Swagger abrirá automaticamente

### Frontend
1. Abra a pasta frontend no VS Code
2. Utilize a extensão Live Server
3. Execute o indexCadastro.html
